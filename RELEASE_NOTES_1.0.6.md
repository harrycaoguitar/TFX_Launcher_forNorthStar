# TFX Launcher 1.0.6

## 中文

- 新增 Windows x64 安装程序，安装后约占用 316 MiB。
- 安装到当前用户的 Programs 目录，可选择其他安装位置。
- 创建桌面和开始菜单快捷方式，并提供卸载程序。
- 安装向导支持简体中文和英语，并提供安装完成后启动选项。
- 保留双客户端管理、DDS / VTF 皮肤及 Mod 功能。

## English

- Add a Windows x64 setup installer. The installed application folder uses about 316 MiB.
- Install for the current user under Programs, with a selectable destination.
- Create Desktop and Start Menu shortcuts and include an uninstaller.
- Provide Simplified Chinese and English installer languages, with a launch option on the finish page.
- Retain dual-client management, DDS / VTF skins and Mod features.

## Validation / 验证

The setup completed successfully in a clean test directory. The installed executable opened a responsive TFX Launcher window. Installation size was approximately 316 MiB. The installer is unsigned.

在独立测试目录中完成安装并验证：安装成功，安装后的程序可打开并显示响应正常的 TFX Launcher 窗口；安装目录约 316 MiB。安装程序未签名。
