# TFX Launcher 1.1.0

## 中文

- 新增国服 / 全球服独立目录安装，可选择 NTFS 磁盘上的独立文件夹，减少切换客户端时的文件替换。
- 新增 EA 模拟器独立页面，支持 EA 账号登录，并可退出后重新登录切换账号。
- 整合 Icepick 模组安装入口，支持在模组安装页面拖入 Icepick、Northstar Mod、DDS 和 VTF 文件，自动识别类型并安装。
- 在模组管理页面新增独立的 Icepick 管理区域，与 Northstar 多人模组分开管理。
- 修复切换至原版游戏后页面空白的问题，恢复原版页面内容与启动按钮显示。
- 更新 Windows 安装器外观，加入品牌背景与图标，支持自定义安装目录。
- 安装向导支持简体中文、繁体中文、英语、德语和法语，并提供可选桌面快捷方式、开始菜单入口与卸载程序。
- 统一启动器界面、应用版本和 Windows 程序文件版本为 1.1.0。
- 在偏好设置中新增合作伙伴 southstar。
- 同步提供开发源码包，包含界面资源、内置组件、构建脚本和安装器工程。

## English

- Added separate installation folders for the CN / Global Northstar clients. Dedicated folders on NTFS drives reduce file replacement when switching clients.
- Added a dedicated EA Emulator page with EA sign-in and account switching through sign-out/sign-in.
- Integrated Icepick installation into the mod installation page. Dropped Icepick, Northstar Mod, DDS and VTF files are automatically recognized and installed.
- Added a separate Icepick management section, keeping Icepick mods apart from Northstar multiplayer mods.
- Fixed the blank page when switching to the vanilla game, restoring the page content and launch button.
- Refreshed the Windows installer with branded artwork and icons, with a selectable installation folder.
- Added Simplified Chinese, Traditional Chinese, English, German and French installer languages, optional Desktop shortcuts, Start Menu shortcuts and an uninstaller.
- Unified the launcher interface, application and Windows executable versions at 1.1.0.
- Added southstar as a partner in Preferences.
- Included a development source archive with interface assets, bundled components, build scripts and the installer project.
