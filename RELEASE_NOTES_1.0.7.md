# TFX Launcher 1.0.7

## 中文

- 修复 CN / Global 北极星客户端安装失败：安装器现已正确包含首次安装所需的客户端资源包。
- 修复启动器版本显示不正确，并统一程序运行时与界面版本信息为 1.0.7。
- 修复更新检查的版本判断，正确处理正式版与预发布版本，避免出现错误的更新提示。
- 修复侧栏版本号硬编码，改为显示当前启动器版本。
- 统一版本信息来源，确保程序版本显示与更新检查保持一致。

## English

- Fixed CN / Global Northstar client installation by including the required first-install payloads in the installer.
- Fixed incorrect launcher version reporting and aligned runtime and interface version information at 1.0.7.
- Fixed update version comparison for stable and prerelease releases to prevent incorrect update prompts.
- Replaced the hardcoded sidebar version with the current launcher version.
- Unified the launcher version source so the displayed version and update checks stay in sync.
