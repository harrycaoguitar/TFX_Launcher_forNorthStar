# TFX Launcher 2.0 · 前端设计大赛作品说明与交互亮点清单

## 一、 作品定位与设计哲学

**TFX Launcher 2.0** 是一款面向《泰坦陨落 1 / 2》与 Northstar 社区的跨版本游戏与模组启动器。
与传统游戏启动器偏爱重度深色堆料、炫光科幻风格不同，本作品以 **「Fluid Tactile Minimalism（流体触感极简）」** 为核心美学：

- **现代开放式编辑排版**：大留白、极细分割线与雕塑感标题，摒弃传统矩形卡片堆砌带来的视觉压迫。
- **同心多圆角胶囊几何语言**：全局严守 6 阶同心圆角阶梯（`--tfx-radius-shell / overlay / well / control / detail / round`），从悬浮胶囊侧栏到滚珠开关、分段胶囊、状态胶囊形成高度统一的圆角韵律。
- **活起来的光学半透明层次**：底层极缓流体环境光场（Living Ambient Mesh）配合 1px 顶部受光边与底部微倒角，让浅色与深色主题下的毛玻璃层产生真实光影纵深。

## 二、 核心交互与动效亮点（零第三方动画库，纯原生 Web 平台实现）

| 亮点模块 | 交互体验 | 核心原生技术 |
|---|---|---|
| **1. 指尖扩散液态换肤** | 点击 17 套主题卡片时，新主题从指尖精确坐标以圆形光波铺满全屏（440ms） | `document.startViewTransition()` + 动态 `clip-path: circle()` |
| **2. 液态拉伸分段胶囊** | 切换泰坦陨落 1/2、Northstar/原版、服务区等分段胶囊时，滑动胶囊中段带细腻横向拉伸与弹性回正 | 自定义阻尼弹簧 + Web Animations API 高斯拉伸曲线 |
| **3. 跨页灵动状态胶囊** | 启动游戏或安装模组时，顶部浮出毛玻璃环形进度胶囊，切去任意页面持续追踪并在完成时描边打勾 | SVG `stroke-dashoffset` 环形进度 + 状态监听 |
| **4. 动态流体容器高度插值** | 武器库展开、安装页载入文件时，容器高度平滑过渡包裹新内容，告别硬跳闪断 | Web Animations API 动态高度插值 |
| **5. 原生景深与离散弹窗退场** | 打开任意弹窗时，底层主画布轻退微缩（`scale(0.986)`）；关闭时带丝滑淡出退场 | CSS `:has(dialog[open])` + `@starting-style` + `allow-discrete` |
| **6. 武器库极简涂装对比滑块** | 在「我的模组 → 武器库」中直接左右拖拽胶囊手柄，实时对比原版哑光与自定义涂装效果 | Pointer Capture + CSS `clip-path: inset()` 实时裁切 |
| **7. 列表 FLIP 重排与滚轮数字** | 模组排序/搜索时行项目平滑滑移；拨动开关时触发弹性轨道挤压、行微亮反馈与纵向滚轮数字 | FLIP 布局动画 + 纵向 Odometer 滚轮过渡 |
| **8. 主题卡微分层 3D 视差** | 悬停 17 套主题缩略卡时，卡片微倾并驱动内部迷你侧栏、标题与按钮按不同深度分层错动 | CSS `perspective` + `--px / --py` 分层视差变量 |
| **9. 纯合成柔和轻触音（默认关闭）** | 顶栏一键开启，切页、拨开关、换肤与启动具备磨砂触点般的细腻声学反馈，零外部音频资源 | 纯 Web Audio API 低通滤波振荡器实时合成 |

## 三、 工程质量与无障碍保障

1. **17 套主题全量 WCAG AA 对比度守护**：涵盖 15 套浅色与 2 套深色精选调色板，所有文字与按钮标签均通过 `>= 4.5:1` 自动化对比度单元测试（`test/prototype-palettes.test.js`）。
2. **完整 5 国语言实时同步**：支持简体中文、繁體中文、English、Deutsch、Français 全界面与所有新增交互组件实时切换，通过多语言完整性测试（`test/prototype-locales.test.js`）。
3. **定制双层柔光焦点环 & 无障碍降级**：贴合胶囊圆角的双层柔光聚焦态，完整响应 `prefers-reduced-motion: reduce`，桌面 `1360×860` 与窄屏底部胶囊坞自适应。
4. **单文件离线评审包**：全资源内联打包为单个独立 HTML 文件（`TFX-Launcher-2.0.0-Demo.html`），评委双击浏览器即可零依赖全功能体验。
